星译付云端-XD

目录：plugins/yunxingyifuxd
受管监控：
在后台“进程管理”同步插件能力后，进入“常驻服务”启动本插件的收款监控；一个服务覆盖本插件全部已启用的主通道和子通道。
更改配置后请“应用配置”；启用前必须停用原独立守护进程，避免两套监控同时运行。
要求已安装系统进程管理服务，PHP CLI 8.1 以上；路径由安装器自动识别，不再使用独立启动命令。


配置项：
  网关地址
  登录方式（应用宝/电脑管家）
  星译付账号
  星译付密码
  AppSession（扫码自动获取，也可手动配置）
  代理模式
  自定义代理地址（自定义 Socks5/HTTP 模式）
  熊猫代理 API 地址（API 模式）

全自动登录流程：
1. 请先确保所填星译付账号可以正常登录。
2. 点击“扫码登录”，由网关完成微信扫码并取得当前微信账号标识。
3. 插件通过网关为目标小程序 wxaceada211a82dcdd 获取一次性 code。
4. 插件使用 RSA 加密后的星译付账号和密码请求登录预处理接口，自动取得 userId、deptId、phone、sign 和 extData。
5. 插件将上述参数和一次性 code 提交星译付商户登录接口，换取 AppSession。
6. 新 AppSession 通过 userInfo 业务接口验证后才保存；任一步骤失败都不会清空或覆盖旧 AppSession。

同账号登录态复用：
- 本插件的微信、支付宝通道只要星译付账号和密码完全一致，即视为同一账号。
- 新增通道保存账号密码后，点击 AppSession 右侧“同步”按钮。
- 同步按钮会查找同账号已有 AppSession，并使用当前通道网络配置请求 userInfo 验证。
- 验证有效后只复制到当前通道，同时回填当前表单；无需打开扫码弹窗。
- 同步只回填当前表单，不会立即写入数据库；必须点击“保存”后才正式保存 AppSession 和商户 ID。
- 扫码登录弹窗只负责当前通道重新登录，不再执行同账号复用检测。
- 复用验证失败不会清空任何通道原有 AppSession。

账号密码只用于星译付登录接口；请求时按星译付格式进行 RSA PKCS#1 v1.5 加密。
若同一账号返回多个商户，第一次选择返回列表中的首个商户并保存商户 ID；以后优先使用已保存的商户 ID。更换账号且旧商户不存在时会自动选择新账号的首个商户。

插件支持微信支付和支付宝支付。创建订单和查询流水直接使用当前 AppSession，是否有效由星译付接口实际返回决定。
配置代理后，扫码网关会收到 X-Proxy-Cluster-* 代理信息并使用代理请求微信；星译付接口由插件本机经配置代理发送。不使用代理时走本机网络。

自定义代理模式填写 http:// 或 socks5:// 地址；API 模式填写熊猫代理 API 地址。两种模式的地址独立保存，切换模式不会互相覆盖。
熊猫代理 API 支持：
- isTxt=1 的 TXT 白名单格式：IP:端口
- isTxt=1 的 TXT账号密码格式：IP:端口:账号:密码
- isTxt=0 的 JSON 白名单格式：obj 数组内的 ip、port
- isTxt=0 的 JSON账号密码格式：obj 数组内的 ip、port、account、password
- proxyType=1 自动按 HTTP/HTTPS 节点使用
- proxyType=2 自动按 SOCKS5 节点使用
- 指定城市和全国随机不会影响解析
熊猫接口限频时按供应商要求间隔至少1秒重试；代理连接失败时自动丢弃缓存节点并提取一次新节点。

新发现的服务默认停用；只有明确启动后才监控，停用服务不会更改支付通道开关。
