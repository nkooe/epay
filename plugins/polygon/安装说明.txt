Polygon USDT 独立插件安装说明

支付方式值：usdtpolygon
插件目录名：polygon

1. 将整个 polygon 目录放到：
   <站点根目录>/plugins/polygon/

2. 本插件不创建支付方式。请在旧系统后台自行添加或确认支付方式，支付方式值必须填写：
   usdtpolygon

3. 插件图标已经放在本目录：
   /plugins/polygon/usdtpolygon.png
   请复制一份到：
   <站点根目录>/assets/icon/usdtpolygon.png
   文件名保持 usdtpolygon.png 不变。

4. 后台刷新支付插件列表，添加通道并选择“Polygon USDT”，填写 Polygon 收款地址和 Etherscan API Key。API Key 使用 ETH V2 API，申请教程：https://docs.etherscan.io/etherscan-v2/getting-an-api-key 。支付有效期固定 600 秒（10 分钟），回调匹配宽限固定 900 秒（15 分钟）；汇率和金额小数位留空时，默认分别为 7.0、4 位。

受管监控：
在后台“进程管理”同步插件能力后，进入“常驻服务”启动本插件的收款监控；一个服务覆盖本插件全部已启用的主通道和子通道。
更改配置后请“应用配置”；启用前必须停用原独立守护进程，避免两套监控同时运行。
要求已安装系统进程管理服务，PHP CLI 8.1 以上；路径由安装器自动识别，不再使用独立启动命令。

6. 监控只在存在本插件的有效未支付订单时查询 Polygon 接口；没有订单时不会查询链上流水。

7. 同一收款地址在10分钟有效期内出现相同折算金额时，插件会自动分配不同的4位金额尾数；已支付订单在原有效期结束前也继续占用尾数，避免重复匹配。

8. 仅匹配至少 3 个确认的 Polygon USDT 交易。到账前会按 TxID 所在区块二次查询，并再次核对交易状态、收款地址、USDT 合约、6 位资产精度及链上原始整数金额；核验不通过不会结算订单。

新发现的服务默认停用；只有明确启动后才监控，停用服务不会更改支付通道开关。
